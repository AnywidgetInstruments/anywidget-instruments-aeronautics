# Widget catalog

The widgets planned by the [specification](specification.md). None is written yet.

| Widget | Shows | Requirement |
|---|---|---|
| `AirspeedIndicator` | Indicated airspeed, colour arcs, never-exceed mark | FLT-001 |
| `AttitudeIndicator` | Pitch and roll: moving horizon and pitch ladder, bank scale | FLT-002 |
| `Altimeter` | Altitude, pressure setting window | FLT-003 |
| `TurnCoordinator` | Rate of turn, slip or skid | FLT-004 |
| `HeadingIndicator` | Heading on a rotating card, heading bug | FLT-005 |
| `VerticalSpeedIndicator` | Climb and descent rates | FLT-006 |
| `HorizontalSituationIndicator` | Heading card, course pointer, course deviation | FLT-007 |
| `PrimaryFlightDisplay` | Speed and altitude tapes around an attitude indicator | FLT-008 |
| `InstrumentPanel` | The basic six in the basic T | FLT-009 |
| Engine gauges | Engine speed, manifold pressure, fuel, temperatures | FLT-010 |

!!! danger "Not for navigation"
    None of these widgets is an aircraft instrument. See the [safety notice](safety.md).
